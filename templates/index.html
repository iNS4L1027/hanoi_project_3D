프로젝트 소개

FastAPI와 JavaScript를 활용하여 하노이의 탑 알고리즘을 3D 공간에서 시각화하는 웹 애플리케이션임 입체 원판의 이동 과정을 관찰하면서 재귀 알고리즘의 동작 원리를 이해할 수 있음

사용 기술

Python · FastAPI

웹 서버를 구성하고 페이지를 제공함

HTML · CSS

페이지 구조와 인터페이스 디자인을 담당함

JavaScript

이동 순서 계산과 애니메이션을 처리함

Three.js

3D 객체, 재질, 조명, 그림자와 카메라를 구현함

알고리즘 설명

최소 이동 횟수 = 2n - 1
